# Keyboard Shortcuts

## Navigation

| Key | Action |
|-----|--------|
| `Enter` | Send message |
| `Ctrl+C` | Cancel / Exit |
| `Ctrl+L` | Clear screen |
| `Up` | Previous message |
| `Down` | Next message |
| `Tab` | Complete command |

## Commands

| Key | Action |
|-----|--------|
| `/` | Open command menu |
| `Esc` | Close menu |
| `Enter` | Run command |

## Editing

| Key | Action |
|-----|--------|
| `Ctrl+A` | Start of line |
| `Ctrl+E` | End of line |
| `Ctrl+U` | Clear line |
| `Ctrl+W` | Delete word |
