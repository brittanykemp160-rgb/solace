# Available Models

## DeepSeek V4.1 Flash Abliterated

- **Provider:** DeepSeek
- **Best for:** Quick back-and-forth, fast responses
- **Tag:** Fast

The default model. Optimized for speed while maintaining quality.

## Kimi K3 Abliterated

- **Provider:** Moonshot AI
- **Best for:** Complex reasoning, multi-step tasks
- **Tag:** Reasoning

Bigger context window, better at deep analysis.

## Qwen 2.5 Coder

- **Provider:** Alibaba
- **Best for:** Code generation, refactoring
- **Tag:** Code

Optimized specifically for coding tasks.

## Switching Models

Use `/model` command:

```
/model deepseek
/model kimi
/model qwen
```
